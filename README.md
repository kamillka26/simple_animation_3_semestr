## Описание проекта

Программа представляет собой интерактивную анимацию системы частиц, созданную с использованием библиотеки `tkinter`. Каждая частица отображается в виде кружка, генерируется в случайном месте и имеет ограниченный срок жизни. Движение и поведение частиц основаны на генераторе случайных чисел, что создаёт эффект естественного «роя» или «облака».

Реализована прозрачность, зависящая от оставшегося времени жизни частицы: в начале жизни кружок яркий и непрозрачный, постепенно он тускнеет и исчезает. Это позволяет визуально отслеживать «старение» каждой частицы и придаёт анимации плавность и глубину.

Дополнительно предусмотрена возможность добавления новых систем частиц по щелчку мыши в произвольном месте поля. Пользователь может создавать несколько независимых источников частиц и наблюдать за их взаимодействием. Программа демонстрирует работу с анимацией, обработкой событий мыши и математическим моделированием.

## Функциональные возможности

### Основной функционал
- Анимация частиц с ограниченным временем жизни
- Прозрачность, зависящая от оставшегося времени жизни частицы
- Несколько независимых систем частиц на одном поле
- Движение частиц в случайных направлениях

### Дополнительный функционал
- Добавление новой системы частиц по клику левой кнопкой мыши
- Слайдеры для настройки частоты появления, времени жизни и скорости частиц
- Горячие клавиши: `Space` — пауза / продолжение, `R` — сброс анимации
- Кнопка «Сброс» на панели управления

## Требования к системе

- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** `tkinter` (встроенная в Python)

## Установка и запуск

### 1. Клонирование репозитория
git clone https://github.com/username/simple_animation_3_semestr.git
cd simple_animation_3_semestr

### 2. Создание и активация виртуального окружения
Windows:

python -m venv venv
venv\Scripts\activate

macOS / Linux:

python3 -m venv venv
source venv/bin/activate

### 3. Установка зависимостей
pip install -r requirements.txt

### 4. Запуск программы
python main.py

### 5. Управление
ЛКМ по холсту - добавить новую систему частиц в точке клика

Space - пауза / продолжение анимации

R - сброс анимации (одна система в центре)

Слайдер «Частота появления» - сколько частиц рождается в секунду (шт/с)

Слайдер «Время жизни» - сколько секунд живёт каждая частица

Слайдер «Макс. скорость» - как быстро частицы разлетаются (пикс/с)

Структура проекта соответствует рекомендованному шаблону из технических требований и обеспечивает разделение ответственности между компонентами:

1) Логика (models/) отделена от отрисовки (renderers/) и интерфейса (widgets/), что упрощает тестирование.

2) Точка входа (main.py) отделена от реализации (src/).

3) Тесты вынесены в отдельную папку tests/, что соответствует требованию и позволяет проверять корректность математики без запуска GUI.

4) Константы размещены внутри соответствующих модулей (app.py для параметров окна, animation_model.py для параметров частиц), так как проект небольшой и отдельный файл был бы избыточным.

**Назначение основных модулей:**

- main.py — точка входа: создаёт приложение и запускает главный цикл.

- src/app.py — класс App: окно, холст, инициализация модели и рендерера, привязка событий (мышь, клавиатура), главный цикл анимации.

- src/models/animation_model.py — класс Model: вся логика и математика (частицы, их движение, время жизни, прозрачность, добавление новых систем).

- src/renderers/renderer.py — класс Renderer: отрисовка частиц на холсте.

- tests/test_model.py — модульные тесты для проверки математической логики модели.
